name: no-git-commits
description: User prefers to handle all git commits themselves
metadata:
  type: feedback
---

No realizar commits automáticos en este proyecto. El usuario prefiere encargarse de crear los commits con su propia firma y mensaje.

**Why:** El usuario quiere mantener el control total sobre los commits y su autoría.

**How to apply:** Cuando completes cambios de código, solo modifica los archivos necesarios. No ejecutes `git add`, `git commit` ni `git push`. Informa al usuario qué cambios se hicieron y déjale que haga el commit.
